# MakiShot Cover Studio

MakiShot 短视频封面编辑器。静态网页，无需构建。

## GitHub Pages

将本目录内容放入仓库根目录，在 Settings → Pages 中选择 Deploy from a branch，分支 main、目录 / (root)，保存。

## 使用

支持四款版式、换图与 Logo、修改文字、导出 1080×1920 PNG、保存独立 HTML 与配置。新选择的图片只在浏览器中处理，不上传至服务器。默认示例图片和品牌 Logo 属于网页公开资源。字体文件按 SIL OFL 1.1 分发，见 OFL.txt。

摄影作品与 MakiShot 品牌素材不授予第三方再利用许可。
