# MakiShot Cover Studio

MakiShot 短视频杂志封面编辑器。支持四款版式、换图与 Logo、修改文字、导出 1080×1920 PNG、保存独立 HTML 和配置。

## GitHub Pages

静态网页，无需构建。在仓库 Settings → Pages 中选择 Deploy from a branch，分支 main，目录 / (root)。

默认摄影作品与 Logo 是公开站点中的示例资源。编辑过程在浏览器本地完成，不含后台和用户素材上传服务。
